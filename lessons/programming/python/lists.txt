TITLE
Python Lists

OBJECTIVES
- Understand Python lists.
- Create lists.
- Access list items.
- Add and remove items.

LESSON
A list stores multiple values in one variable.

Example:

fruits = ["apple", "banana", "orange"]

Python lists use indexes beginning at 0.

Example:

print(fruits[0])

This prints the first item.

Items can be added using append().

Example:

fruits.append("mango")

Items can be removed using remove().

Example:

fruits.remove("banana")

EXAMPLE
numbers = [10, 20, 30]

numbers.append(40)

print(numbers)

KEY POINTS
- Lists store multiple values.
- List indexes start at 0.
- append() adds an item.
- remove() removes an item.
- Lists can contain different types of values.
