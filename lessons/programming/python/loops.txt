TITLE
Python Loops

OBJECTIVES
- Understand loops.
- Use for loops.
- Use while loops.
- Repeat instructions efficiently.

LESSON
A loop repeats a block of code.

A for loop can iterate through a sequence.

Example:

for i in range(5):
    print(i)

A while loop continues while a condition is true.

Example:

count = 0

while count < 5:
    print(count)
    count += 1

The range() function is commonly used with for loops.

EXAMPLE
for number in range(1, 6):
    print(number)

KEY POINTS
- Loops repeat code.
- for loops are useful for iterating through sequences.
- while loops continue while a condition is true.
- range() generates a sequence of numbers.
