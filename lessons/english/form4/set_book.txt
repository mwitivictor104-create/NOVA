SET BOOK

When studying a set book, examine:

• Plot
• Characters
• Themes
• Setting
• Conflict
• Style
• Literary devices
• Important events
• Lessons

For every major character, identify:
1. Character traits.
2. Important actions.
3. Relationships.
4. Contribution to the story.

PRACTICE

Choose a character from your current set book
and explain three important character traits.
