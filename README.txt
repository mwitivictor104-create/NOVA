NOVA AI ASSISTANT
=================

Project directory:
    ~/NOVA

Start NOVA:
    cd ~/NOVA
    python main.py

Text commands:
    hello
    help
    status
    subjects
    topics mathematics form1

Learning:
    teach mathematics form1 numbers
    teach mathematics form1 fractions
    teach mathematics form2 indices
    teach mathematics form3 quadratic_equations
    teach mathematics form4 calculus

Memory:
    remember name = NOVA
    recall name
    memory
    forget name

Daily features:
    daily devotion
    motivation

Voice:
    Choose Voice from the NOVA menu.

This is a reconstructed NOVA foundation.
More modules can be added without replacing
the whole project.
